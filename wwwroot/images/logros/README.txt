LOGROS — SPRITES (Fase 9, identidad pixel)
===========================================

Íconos pixel-art de cada logro. PNG con FONDO TRANSPARENTE, cuadrados
(ej. 48x48 o 64x64). El nombre del archivo tiene que ser el id del logro + .png.
Si un archivo no existe, la app muestra el emoji del logro como respaldo.

Los bloqueados se muestran en gris automáticamente (filtro CSS), así que alcanza
con un solo sprite a color por logro.
